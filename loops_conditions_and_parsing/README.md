# Shell, loops, conditions and parsing

- 1-for_best_school: displays "Best School" 10 times with a for loop
- 2-while_best_school: displays "Best School" 10 times with a while loop
- 3-until_best_school: displays "Best School" 10 times with an until loop
- 4-if_9_say_hi: "Best School" 10 times, with "Hi" after the 9th
- 5-4_bad_luck_8_is_your_chance: "bad luck" on the 4th, "good luck" on the 8th, "Best School" otherwise
- 6-superstitious_numbers: numbers 1 to 20 with bad luck notes for China, Japan and Italy
- 7-clock: displays hours 0 to 12 and minutes 1 to 59
- 8-for_ls: lists the directory showing the part of each name after the first dash
- 9-to_file_or_not_to_file: reports whether the school file exists, is empty, and is a regular file
- 10-fizzbuzz: FizzBuzz from 1 to 100
- 11-read_and_cut: displays username, user id and home directory from /etc/passwd
- 12-tell_the_story_of_passwd: tells a story from /etc/passwd with while and IFS
- 13-lets_parse_apache_logs: displays visitor IP and HTTP status code from apache-access.log
- 14-dig_the-data: counts occurrences of each IP and status code, most frequent first
